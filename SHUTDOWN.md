# Завершення та перепідключення

Core (`python -m pipeline.main`) і клієнт (`python -m senko_client`)
обробляють SIGINT (Ctrl+C) і SIGTERM, який надсилає systemd під час зупинки
сервісу. Обидва сигнали запускають асинхронне завершення.

Core очікує скасування робочих задач, завершує Codex, закриває сервер,
активні з’єднання, HTTP-клієнти й SQLite історії, видаляє файл сокета.
Клієнт зупиняє мікрофон, відтворення, сокет і задачу перепідключення.

Клієнт робить першу спробу підключення одразу. Якщо core недоступний або
з’єднання обірвалося, наступні спроби відбуваються з паузою 5 секунд.
Запити під час відсутності з’єднання та незавершені запити під час обриву
отримують статус 503. Аудіо, записане без з’єднання, не накопичується для
повторного надсилання.

Під час запуску через systemd або контейнер сигнал має доходити до процесу
Python. Для shell-обгорток використовуйте `exec`, як у `run.sh`.
Залишайте час на завершення активних операцій: примусовий SIGKILL не запускає
очищення ресурсів. Конфігурацію встановлених systemd-сервісів цей патч не змінює.

Перевірка:

```sh
PYTHONPATH=client/src:core/src:protocol/src .venv/bin/python -m unittest discover -s tests -p test_socket_lifecycle.py -v
```
